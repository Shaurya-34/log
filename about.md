# About · Shaurya

Hi, I'm Shaurya. I write software and keep this log as a record of the things I build, read, and try to understand. The subjects move around: machine learning, graphics, programming, computation, mathematical ideas, and small experiments that are easier to understand by implementing them than by reading about them.

The site is a collection of working notes rather than polished documentation. I start with a question, follow the interesting parts, build something when code helps, and write down what survived the experiment. Some pieces are explanatory, some exploratory, and some are simply records of a rabbit hole worth keeping.
